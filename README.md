# 📝 Smart Task Tracker

A sleek, responsive, and lightweight **Task Management Application** built using pure HTML, CSS, and vanilla JavaScript. It allows users to manage daily tasks efficiently with automatic data persistence using browser `localStorage`.

---

## ✨ Features

- ➕ **Add New Tasks:** Quick and easy task creation.
- ✅ **Toggle Completion:** Click on any task to mark it as completed or active.
- 🗑️ **Delete Tasks:** Remove individual tasks or clear all at once.
- 💾 **Data Persistence:** Tasks remain saved even after refreshing or closing the browser (`localStorage`).
- 📱 **Fully Responsive:** Beautiful modern UI optimized for both desktop and mobile screens.
